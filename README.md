# Financial Dashboard – Excel Project

## 📊 Project Overview
This project is an **interactive Financial Dashboard built using Microsoft Excel**.  
It converts raw financial transaction data into meaningful insights through structured data modeling, pivot tables, formulas, and dynamic visualizations.

The dashboard is suitable for **business reporting, financial analysis, and portfolio demonstration**.

---

## 🎯 Project Objectives
- Analyze **income vs expenses**
- Track spending across **categories**
- Compare financial performance by **region**
- Understand usage of different **payment methods**
- Present insights through an **interactive dashboard**

---

## 🗂 Dataset Description
The dataset represents structured financial transactions with the following fields:

- **Date** – Transaction date  
- **Transaction ID** – Unique identifier  
- **Account Name** – Income, Expense, or Asset  
- **Category** – Rent, Sales, Marketing, Equipment, etc.  
- **Amount** – Transaction value (positive and negative)  
- **Transaction Type** – Income or Expense  
- **Payment Method** – Cash, Credit Card, Bank Transfer  
- **Region** – North, South, East, West  
- **Month** – Used for trend analysis

## 🧾 Code Notes (Important)
This project does **not use traditional programming code** (e.g. Python, SQL, or JavaScript).

Instead, the “logic” of the project is implemented using **Excel-based techniques**, including:

### Excel Formulas
- Conditional logic to separate **Income and Expenses**
- Calculated fields for aggregation and summaries
- Date-based grouping for monthly analysis

### Pivot Tables
- Aggregation of transaction data
- Category, region, and payment method analysis
- Dynamic recalculation based on slicer selections

### Slicers
- Interactive filtering across multiple pivot tables
- Enables real-time dashboard updates

> 📌 Note: No VBA macros were used.  
> The project is intentionally built using **core Excel analytics features** to ensure compatibility and transparency.
